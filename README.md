# 🌍 ClimateScope – Interactive Climate Dashboard

## 📌 Project Overview
ClimateScope is an interactive climate analytics dashboard that enables users to explore global weather data, visualize climate patterns, and detect extreme weather conditions.

The project transforms raw weather datasets into meaningful insights using dynamic and interactive visualizations.

---

## 🎯 Objectives
- Analyze global climate data efficiently  
- Provide interactive visualizations for better insights  
- Identify climate trends and seasonal patterns  
- Detect extreme weather events using statistical methods  

---

## 🚀 Features

### 🌐 Global Climate Overview
- Displays key metrics:
  - Average Temperature  
  - Average Humidity  
  - Average Wind Speed  
  - Total Records  

### 🗺️ Interactive Maps
- Global temperature choropleth map  
- Weather observation map with location markers  

### 📈 Climate Trend Analysis
- Monthly and yearly temperature trends  
- Seasonal pattern identification  

### 🌍 Regional Comparison
- Compare temperature, humidity, and wind speed between countries  

### ⚠️ Extreme Weather Detection
- Detects anomalies using Z-score method  

### 🎛️ User Interaction
- Filters:
  - Country selection  
  - Month selection  
  - Temperature range  

---

## 🛠️ Tech Stack

- Pandas  
- Plotly  
- NumPy
